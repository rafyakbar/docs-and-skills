# README Templates

Not all READMEs should look the same. Based on project exploration, classify into one of four types.

## Type A: Application

**Examples:** Web apps, SaaS, Dashboards, Laravel apps, Vue apps
**Focus:** Screenshots, Features, Quick Setup, Deployment

```
# Title
[Hero / Badges]
> Short description

## Is This Project For You?

## Features

## Screenshots / Demo (optional)

## Tech Stack

## Quick Start

## Configuration (optional)

## Architecture (optional)

## Testing

## Deployment

## FAQ

## Roadmap
```

## Type B: Library / Package

**Examples:** npm packages, Composer packages, PyPI packages, SDKs
**Focus:** Installation, Usage, API, Examples

```
# Title
[Badges]
> Short description

## Is This Project For You?

## Installation

## Quick Start

## Usage

## API Reference (optional)

## Examples
```

## Type C: Tool / CLI

**Examples:** Codex tools, OpenCode tools, CLI generators, automation scripts
**Focus:** Installation, Commands, Examples, Configuration

```
# Title
[Badges]
> Short description

## Is This Project For You?

## Installation

## Usage / Commands

## Examples

## Configuration
```

## Type D: Knowledge Repository

**Examples:** AI Skills, Prompts, RPS documents, Datasets, SOPs, AI Workflows, Curriculum, Templates
**Focus:** Overview, Structure, Workflow, Activation Rules, Constraints

```
# Title
[Hero section]
> Short description

## Is This Project For You?

## Overview

## What This Project Can Do

## Input / Output

## Directory Structure

## Workflow

## Activation Rules (if applicable)

## Constraints

## Required Files

## Configuration (if applicable)

## Example

## Works Best With (for AI projects)
```
